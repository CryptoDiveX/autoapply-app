# Public HTTP error evidence

1. Preserve HTTP error status, exact requested URL, final URL, retrieval timestamp and response body on the first request. Python urllib HTTPError exposes its body through read(); an exception message alone loses the employer's actual vacancy disposition.
2. Treat current official HTTP410 plus explicit position-no-longer-active wording as closure of that exact vacancy, even when cached extraction retains job copy or Apply text. Do not infer employer-wide closure.
3. If an earlier handler omitted the body, recover only read-only response evidence. Never repeat candidate entry, uploads, sends or submissions to improve an audit.
4. Keep JS-shell HTTP200 and a public API404 separate from visible exact-role closure. A failed case-sensitive board lookup or missing extraction is unresolved currentness, not proof that a vacancy is dead.
