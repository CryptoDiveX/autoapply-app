# Resume template incident and reference

Date: 2026-09-04.

## User correction

Vasya objected that submitted resumes and cover letters did not match the provided Word reference format and had no photograph. This is a quality failure.

## Authoritative resume layout reference

Use these files as the visual and structural source for resume formatting:

1. `~/Downloads/Alexander-Mercer-Resume-InDrive-Photo_2.docx`
2. `~/Downloads/Alexander-Mercer-Resume-InDrive-Photo_2.pdf`

## Required visual traits

1. Left-aligned header, not centered.
2. Large name line reading like the provided sample.
3. Subtitle headline directly under the name.
4. Contact block under the headline.
5. Circular photo at the top right.
6. Section headings with the same uppercase styling and horizontal rules.
7. Compact professional typography and spacing rhythm matching the sample.
8. Role titles on the left and dates right-aligned.
9. Company links and separator style matching the sample.
10. Applicable icons or emojis from the provided Word reference must be preserved where relevant.

## What failed

Generated HTML resumes, for example Cohere, were centered, text-only, and had no photo. They did not resemble the sample Word/PDF template.

## Operational rule

Do not submit future applications with generic rebuilt HTML resumes. Generate from the reference template or a faithful clone of it. Before upload, render page 1 and compare visually against the InDrive Photo sample. If the photo or layout system is missing, stop and log a document-format blocker instead of submitting.
