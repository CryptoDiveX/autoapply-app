# Public careers-link projection safety

1. Match the visible anchor label and parsed URL path for careers discovery, not arbitrary query text. Signed product-editor demo URLs can contain incidental job or company substrings inside tokens.
2. Before saving or printing derived link projections, remove security-bearing query values such as session_token, sig, signature and access tokens. Retain only origin/path and a security_query_excluded flag, and never follow these demo/security links for job research.
3. Preserve ordinary exact job/source URLs unchanged. Raw public HTML may remain local provenance; do not promote its embedded demonstration credentials into a route, output or application action.
4. If a noisy projection was already saved, recover only the local projection and discovery helper. Do not refetch the employer or repeat any candidate or outbound action to repair this evidence step.
6. Use the normal parallel tool wrapper for independent Hermes tool requests, not ThreadPoolExecutor calls into the execute_code hermes_tools bridge. Concurrent bridge calls can misassociate response envelopes, so assert expected response schemas before saving retrieved evidence. If mixed envelopes appear, quarantine affected research artifacts, reset the kernel and recover only read-only retrieval through ordinary calls or sequential bridge calls. Never replay outbound actions to repair research provenance.
5. Capture exact href values for visibly labeled Open positions, Browse current openings and View current openings controls even when the destination path is `/` on an ATS domain. A path-only `/jobs` or `/careers` filter can omit a real Pinpoint board. Include observed application iframe sources in the first sanitized snapshot, because Airtable and Loxo inventories may exist only inside the frame. Whitelist stable public board parameters such as Greenhouse for=<observed-board> while excluding transient validityToken and other security-envelope parameters, including on ordinary ATS iframe URLs rather than only CAPTCHA frames. Inspect retained complete link artifacts before reopening a parent merely to repair a filtered projection; preserve challenge/security URL exclusions.
