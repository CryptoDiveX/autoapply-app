# LinkedIn profile-menu recovery

1. When a profile initially renders only its header, wait for its remaining content and re-read the existing More menu and actual custom-invite anchors before toggling More again. Delayed hydration does not establish a blocked invitation route. During ordinary profile navigation, CDP can briefly return `-32000 Cannot find default execution context` before the destination document initializes. Retain the exact owned target and recover only snapshot readiness with bounded read-only retries under a new evidence filename; never open a duplicate profile, restart the browser or replay an invitation for that transient readback error.
2. A current profile More button can have a null aria-label. Preserve its observed componentkey and canonical profile header, click only that exact live control, then bind the resulting observed invite href to the intended profile. Require the exact recipient's named dialog before persisting intent or sending. Match componentkey with an exact getAttribute comparison or a correctly quoted CSS attribute selector; an unquoted UUID beginning with a digit can make querySelector reject an otherwise valid observed control. After inspecting Contact info, dismiss only that overlay and allow its canonical profile URL/header to settle before a strict profile assertion. Recover these pre-intent lookup failures without replaying an invitation.
3. Recover menu lookup and readiness read-only. Never substitute a suggested person's Connect control, construct a profile/invite URL, or repeat an invitation to repair evidence.
4. Inspect both visible buttons and anchors for recipient-specific Pending/withdraw controls. LinkedIn can render Pending as an `<a>` with `aria-label="Pending, click to withdraw invitation sent to [recipient]"`; an empty button-only query is a verifier-schema failure, not a failed invitation. Preserve the original send intent/action and recover only exact-profile readback, never Send again.
5. Follow an employer's exact published LinkedIn destination even when it uses `/school/` rather than `/company/`. Educational nonprofits can use school pages for their official organization identity. Inspect the observed About link, require the employer name, matching official website and labeled headquarters, and corroborate the operating identity on the official site. Do not construct a company slug or treat unrelated search results as a headquarters conflict.
