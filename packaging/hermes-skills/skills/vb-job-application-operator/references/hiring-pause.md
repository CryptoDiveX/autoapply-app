# Hiring pauses and careers-to-help handoffs

1. Check the current official careers header before relying on retained role pages. A visible company-wide hiring pause overrides stale recruiting copy and still-linked job cards unless newer role-specific employer evidence explicitly reopens hiring. Preserve both sources and do not submit or substitute an inbox.
2. Scope negative findings precisely. An incomplete Open Roles widget is an unresolved inventory, not proof that the employer has no openings. Wait boundedly, inspect observed frames and current public bundle before deciding.
3. Inspect actual role-card destinations and clickable ancestors. If the card points to a general help center with no hiring instructions, it is not a submit-ready application. Follow only observed links, keep support and recruiting routes distinct, and do not use a customer-support address to bypass a missing application path.
4. Record preflight-only findings without application credit or unnecessary hypothetical tracker records. Preserve existing target status and original date when appending changed route evidence.
